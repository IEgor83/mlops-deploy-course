# Занятие 18. Зачёт

## Формат

12 минут на человека: 7 минут живое демо + 5 минут вопросы.
Полные критерии — в [`docs/assessment.md`](../../docs/assessment.md).

## Обязательные условия

Не выполнено любое — «не зачтено» независимо от набранных баллов:

1. Итоговый проект набрал ≥ 20 из 36 по рубрике.
2. CI зелёный на последнем коммите `main`.
3. Сервис поднимается одной командой на машине преподавателя.

Первые два проверяются за сутки до защиты. Если что-то красное —
у вас есть сутки.

## Накануне

Прогоните **в новой папке**:

```bash
git clone <ваш-репозиторий> /tmp/exam && cd /tmp/exam
dvc pull
docker compose -f docker/docker-compose.yml up -d
sleep 30
curl -s localhost:8000/health
curl -s -X POST localhost:8000/predict -H 'Content-Type: application/json' -d @examples/request.json
pytest -q
docker compose -f docker/docker-compose.yml down -v
```

Упала хотя бы одна команда — вы не готовы.

Скачайте заранее всё, что понадобится:

```bash
docker compose -f docker/docker-compose.yml pull
docker pull ghcr.io/<ваш-логин>/<ваш-репо>:1.0.0
```

Интернет в аудитории может не работать. Это не считается уважительной
причиной — предупреждение выдано.

Последний коммит — **за сутки** до защиты.

## Структура демо (7 минут)

| Мин | Что показываете |
|---|---|
| 0:00–0:30 | Задача и что построено. Два предложения |
| 0:30–1:30 | Чистый клон, `dvc pull`, запуск стенда |
| 1:30–2:30 | `/predict`, `/docs`, версия модели в ответе |
| 2:30–3:30 | MLflow: эксперименты, реестр, Production |
| 3:30–4:30 | CI: зелёный workflow, quality gate |
| 4:30–5:30 | Grafana: дашборд, алерты |
| 5:30–6:30 | Evidently: отчёт о дрейфе |
| 6:30–7:00 | Что бы доработали дальше |

Живой запуск, не слайды. Презентация вместо демо — минус 5 баллов.

Таймер жёсткий: на 7-й минуте демо останавливается, докуда дошли —
то и зачтено. Отрепетируйте вслух.

## Вопросы

**Два по вашему проекту.** Не общие — по конкретной строке в вашем
репозитории. Будьте готовы объяснить любое решение в любом файле,
включая «почему здесь `try/except`» и «почему этот порог».

Часть вопросов практические: вас могут попросить прямо сейчас уронить
MLflow и показать, что происходит с сервисом, или отправить запрос
с несуществующей категорией.

**Один из списка** в `docs/assessment.md`, раздел «Вопросы к зачёту».
Пройдите список заранее и отметьте те, на которые не отвечаете уверенно.

## Что взять

- Ноутбук и зарядку
- Переходник для проектора
- Скачанные образы и зависимости
- Ссылку на репозиторий и на опубликованный образ

## Если не зачтено

Пересдача в том же формате: защита проекта + три вопроса из списка
вместо одного. Требования не снижаются.

Если проблема в несданных ДЗ, а проект рабочий — досдайте ДЗ
до пересдачи, они учитываются.
