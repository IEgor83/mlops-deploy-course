## 4. Перед зачётом (за две недели)

> До защиты осталось две недели. Проверьте себя **в новой папке**,
> не в рабочей копии:
>
> ```
> git clone <ваш-репозиторий> /tmp/check && cd /tmp/check
> dvc pull
> docker compose -f docker/docker-compose.yml up -d
> curl -s localhost:8000/health
> pytest -q
> ```
>
> Упала хотя бы одна команда — вы не готовы. Самая частая причина
> незачёта: проект работает только на машине автора.
>
> Также обязательно: зелёный CI на последнем коммите main
> и опубликованный образ.
>
> Скачайте заранее docker-образы и зависимости — интернет в аудитории
> может не работать, и это не будет уважительной причиной.
>
> Последний коммит принимается за сутки до защиты.
> Регламент защиты: https://github.com/alsu124/mlops-deploy-course/blob/main/docs/assessment.md
