# Теория курса

Лекций в курсе нет: все 36 часов — практика. Но зачёт спрашивает не только
«что вы нажали», а «почему так, а не иначе». Эти конспекты и есть теория —
их читают дома, по 20–30 минут перед занятием.

## Как читать

К каждому занятию привязан один конспект. Читать **до** пары: на паре
вы будете делать то, что здесь объяснено, и без чтения половина действий
превратится в набор команд из методички.

| Читать перед | Конспект | Объём |
|---|---|---|
| занятие 1 | [Что такое MLOps](01-what-is-mlops.md) | 25 мин |
| занятия 2–3 | [Воспроизводимость](02-reproducibility.md) | 25 мин |
| занятия 4–5 | [Версионирование данных и пайплайны](03-data-and-pipelines.md) | 25 мин |
| занятия 6–7 | [Эксперименты и модели как артефакты](04-experiments.md) | 25 мин |
| занятие 8 | [Тестирование ML-систем](05-testing.md) | 30 мин |
| занятие 9 | [CI/CD для машинного обучения](06-cicd.md) | 20 мин |
| занятия 10–13 | [Вывод модели в продакшн](07-serving.md) | 30 мин |
| занятия 14–15 | [Мониторинг и дрейф](08-monitoring.md) | 30 мин |
| занятия 16–17 | [Жизненный цикл модели](09-lifecycle.md) | 25 мин |

Итого около 4 часов чтения на семестр — по 15 минут в неделю.

## Как устроен каждый конспект

* **Проблема** — зачем это вообще понадобилось
* **Как устроено** — механика, с примерами из вашего же проекта
* **Частые заблуждения** — то, на чём спотыкаются на зачёте
* **Вопросы к зачёту** — какие пункты из `../assessment.md` закрывает конспект

## Чего здесь нет

Здесь нет курса по машинному обучению: предполагается, что вы умеете
обучить модель. Здесь нет и справочника по командам — они в методичках
занятий. Здесь только то, что нужно понимать, чтобы принимать решения.
