## 🔧 СТЕК И ИНСТРУМЕНТЫ

**Языки и фреймворки:**
- Python 3.11+
- scikit-learn, pandas, numpy (ML)
- FastAPI (REST API)

**Инструменты воспроизводимости:**
- Git (контроль версий кода)
- DVC (контроль версий данных)
- make (автоматизация команд)

**Инструменты качества:**
- pytest (unit-тесты)
- pandera (валидация данных)
- ruff (линтер)
- pre-commit (автопроверка перед коммитом)

**Инструменты экспериментирования:**
- MLflow (отслеживание экспериментов)
- MLflow Registry (управление моделями)

**Инструменты CI/CD:**
- GitHub Actions (автоматизация)
- Docker (контейнеризация)

**Инструменты мониторинга:**
- Prometheus (сбор метрик)
- Grafana (визуализация)
- Evidently (мониторинг данных)

**Инструменты оркестрации:**
- Prefect (планирование и автопереобучение)

**Инструменты для разработки:**
- VSCode / PyCharm (IDE)
- Docker Desktop (локальная контейнеризация)

## 🚀 КАК ИСПОЛЬЗОВАТЬ ЭТОТ КУРС

```bash
# 1. Читаете student-guide.md

# 3. Следуете инструкциям в student-repo-guide.md
```

### Для преподавателя (неделя до курса):

```bash
# 1. Читаете lecture-00-introduction.md
# 2. Читаете course-roadmap.md
# 3. Читаете docs/setup.md (ставите окружение)
# 4. Запускаете эталон (mlops-deploy-course-reference): make all
# 5. Поднимаете бота: python -m bot.main
# 6. Проверяете что всё работает
# 7. Раздаёте студентам ссылку на шаблон и бота
```

### На каждом занятии:

```bash
# Преподаватель:
# 1. Читает lessons/NN-*/plan.md (тайминг)
# 2. Показывает демо: python tools/make_demo_repo.py
# 3. Раздаёт /task N через бота

# Студент:
# 1. Читает lessons/NN-*/handout.md
# 2. Делает задания пошагово
# 3. Коммитит и пушит в свою ветку
# 4. Создаёт PR
# 5. Пушит в свой репозиторий
```
