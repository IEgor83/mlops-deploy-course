❓ Что такое MLOps?

MLOps = Machine Learning Operations

Практики инженерии, которые позволяют:

  • 🔄Воспроизвести ML-модель (один код + одни данные = одна модель)
  • 📊Отслеживать её качество в production (логи, метрики, дашборды)
  • 🧪Тестировать её поведение (unit-тесты, integration-тесты)
  • 🚀Развёртывать в production автоматически (CI/CD)
  • 👁️Мониторить её в реальном времени (дрейф данных, падение качества)

Работает в Jupyter

❌ Проблема: только на своей машине

ML Engineer

Работает в production

make install make data make train make test docker compose up

✅ Цель: система в production

✅ Преимущество: работает везде

🎯 Почему это важно?

Сценарий 1: Бизнес просит улучшить модель

Без MLOps:
  • ❓ Какой сид использовал?
  • ❓ Какие параметры в grid search?
  • ❓ Какие данные отфильтровал?
  • ❌ 3 дня археологии кода
С MLOps:
  • ✅ Меняю learning_rate в params.yaml
  • ✅ make train (воспроизводится)
  • ✅ Вижу результат в MLflow
  • ✅ Готово за 2 часа, улучшил на 3%

🛠️ Наш стек инструментов

  • 🐍Python 3.11 + Git — основа
  • 📦DVC — версионирование данных
  • ⚙️make + params.yaml — параметризация и автоматизация
  • 🧪pytest — тесты, ruff — качество кода

  • 🤖Prefect — оркестрация и автопереобучение

📏 Правила проекта (действуют всегда!)

  • 🚫 Нет абсолютных путей
    ❌ /Users/anna/data.csv → ✅ data/raw/churn.csv
  • 🚫 Нет магических чисел в коде
    ❌ max_depth=7 → ✅ params["train"]["max_depth"]
  • 🚫 Данные и модели не коммитятся в Git
    С недели 4: используем DVC вместо Git
  • 🚫 Секреты только через окружение
    ❌ API_KEY="sk-..." → ✅ os.getenv("API_KEY")
  • 🚫 Только PR для main
    Работаем в feature-ветках, code review перед слиянием

🏆 Что вы создадите

Один сквозной проект, который на протяжении семестра эволюционирует:

Неделя 1: Модель → Структурированный код (src/train.py) Неделя 5: Код → Воспроизводимый пайплайн (dvc.yaml) Неделя 9: Пайплайн → Автоматически проверяется (GitHub Actions) Неделя 13: Модель → REST API в контейнере (Docker) Неделя 17: API → Монитируется и переобучается (Prometheus + Prefect)
